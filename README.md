# RDAD

واجهة دردشة عربية تتصل بذكاء اصطناعي عبر واجهة خادم آمنة.

## تشغيل الذكاء الاصطناعي

المشروع يحتاج إلى استضافة تدعم وظائف الخادم مثل Vercel؛ GitHub Pages وحده لا يشغّل `api/chat.js`.

1. اربط هذا المستودع بحسابك في Vercel واستورد مشروع `abutalal0ai/RDAD`.
2. من إعدادات المشروع في Vercel افتح **Settings → Environment Variables**.
3. أضف المتغير `OPENAI_API_KEY` وضع فيه مفتاح API الخاص بك. لا تضع المفتاح في ملفات الموقع ولا ترسله في المحادثة.
4. (اختياري) أضف `OPENAI_MODEL` لاختيار نموذج متاح لحساب API.
5. أعد نشر المشروع من **Deployments → Redeploy**.

بعد النشر، تستدعي الواجهة `/api/chat` ويرسل الخادم الطلب إلى OpenAI Responses API. استخدام API قد يترتب عليه رسوم حسب حسابك واستهلاكك.

## الملفات

- `index.html`: واجهة الدردشة العربية.
- `api/chat.js`: نقطة الخادم التي تحفظ المفتاح بعيدًا عن المتصفح وترسل الرسائل إلى نموذج الذكاء الاصطناعي.
